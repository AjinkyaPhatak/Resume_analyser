# Reproducing the paper

*Do Entity-Level Resume Matchers Leak Less Demographic Signal? A Counterfactual Fairness
Audit of Semantic Resume–Job Matching.*

Every number, table and figure comes from the commands below, run from the **repo root**
in order. Each experiment logs its config, git commit and environment to a `run_meta.json`.
All randomness is seeded (`seed: 13` in `configs/base.yaml`). Any experiment accepts
`--subset N` for a quick run and `--set key=value` to override config values.

## 0. Environment

- Python 3.14, Windows or Linux. The repo's venv lives at `venv/` (on Linux/macOS use
  `venv/bin/python` instead of `venv/Scripts/python.exe`).
- `venv/Scripts/python.exe -m pip install -r research/requirements.txt`
- GPU strongly recommended (fine-tuning, cross-encoder, dense encoders). The CUDA torch
  command is in `requirements.txt`. Everything falls back to CPU automatically, just slower.
- Tests: `venv/Scripts/python.exe -m pytest research` (fast); `-m slow` adds real-model tests.

| Wikidata Indian names | run the SPARQL in `research/data/wikidata_india_names.rq` at query.wikidata.org and save the CSV (snapshot date is recorded in `QUERY_META.json`) | `research/data/raw/names/wikidata_india/india_given_names.csv` |

The Wikidata snapshot can't be pinned by revision: re-querying can give slightly different
counts, so the paper's numbers use the committed snapshot's hash and retrieval date.

## 2. Pipeline

| Step | Command | Output | Approx. time (RTX 2060) |
|---|---|---|---|
| Extraction eval (Table: extraction) | `venv/Scripts/python.exe -m research.experiments.eval_extraction` | `results/extraction.md`, `results/extraction/metrics.csv` | 10 min |
| Fine-tune extractor (3 seeds) | `venv/Scripts/python.exe -m research.experiments.train_extractor --set seed=13` (then 14, 15) | `research/models/jobbert_skillspan/seed*/` | 15 min / seed |
| Data, map, pools | `venv/Scripts/python.exe -m research.experiments.prepare_data` | `data/processed/`, `data/occupation_map.csv`, `results/data_stats.md` | 5 min |
| Counterfactuals | `venv/Scripts/python.exe -m research.experiments.make_perturbations` | `data/processed/perturbations_*.parquet`, `results/perturbation_samples.md` | 20 min |
| Dev-only selection of the main method | `venv/Scripts/python.exe -m research.experiments.run --config configs/selection.yaml` | `results/selection_dev/`, `results/selection_dev_summary.md` | 30 min |
| **Main experiment** | `venv/Scripts/python.exe -m research.experiments.run --config configs/main.yaml` | `results/main/`, `results/main_summary.md` | 1.5–2 h |
| Ablations | `venv/Scripts/python.exe -m research.experiments.run --config configs/ablations/<name>.yaml` for `entity_types`, `aggregation`, `backbone`, `extractor` | `results/ablation_<name>/` | 10–60 min each (caches) |
| Near-miss band sweep | `venv/Scripts/python.exe -m research.experiments.nearmiss_sweep` | `results/nearmiss_sweep.md`, `results/summaries/figures/nearmiss_*` | 10 min |
| **Figures + LaTeX tables** | `venv/Scripts/python.exe -m research.analysis.make_all` | `results/summaries/figures/*.pdf|png`, `results/summaries/tables/*.tex` | 1 min |
| Human annotation | `venv/Scripts/python.exe -m research.annotation.sample`; `streamlit run research/annotation/app.py`; `venv/Scripts/python.exe -m research.annotation.agreement` | `annotation/labels/`, `results/annotation_agreement.md` | people: 4–6 h each |

Caches (`research/.cache/`) make reruns fast: extracted spans, embeddings and pair scores are
keyed by model/extractor fingerprint and text hash. Deleting the cache only costs time.

## 4. Design decisions a reader should know

- Splits: BiasBios's official train/dev/test split; dev/test bios that duplicate an earlier
  split were removed. Dev is used for every choice (thresholds, the near-miss band, the main
  method's configuration); test is used only for reporting.
- Main method: chosen on DEV by a rule declared before running (`configs/selection.yaml`):
  highest dev nDCG@10; fairness metrics were not used for selection.
- Statistics: means over JD pools; 95% cluster-bootstrap CIs over pools (1000 resamples);
  paired sign-flip permutation tests over pools, Holm-corrected; tie-aware ranking metrics.
- Counterfactual gaps are normalised by the SD of the pool's original scores (scorers'
  scales differ) and reported over changed bios.
- See `CLAUDE.md` for the full per-phase notes and known limitations.
